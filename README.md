# 桌面待办 · Desktop Todo

一个轻量的 Windows 桌面待办工具：半透明面板、中文界面、时钟与农历，事项保存在本地。

![桌面待办界面](素材/界面预览.png)

## 功能

- 添加、编辑、完成、恢复和删除待办；支持撤销最近一次删除。
- 待办与已完成分类，右键编辑或上移事项。
- 半透明面板，可拖动、锁定位置、调整透明度、显示时钟、置顶。
- 右上角独立的“收起到托盘 / 展开或收起 / 设置”按钮，展开和收起时箭头中心保持不变。
- 双击托盘图标恢复；可选开机启动。
- 自动保存、上一版本备份、损坏恢复和写入保护。
- 鼠尾草绿与米白勾选图标，由 AI 生成，包含多种尺寸。

## 运行

适用于安装了 **.NET Framework 4.8** 的 Windows 10 / 11。

1. 在 GitHub 仓库中选择 **Code → Download ZIP**，下载并解压完整项目。
2. 双击根目录的 **桌面待办.exe**。请保留旁边的 `桌面待办.exe.config`。
3. 在底部输入事项，按 **Enter** 添加。双击事项文字编辑，**Esc** 取消编辑。

程序不依赖 Python、Node.js 或 .NET 8，无需联网。开机启动默认关闭，需要时从设置菜单开启。详细操作见 [使用说明](使用说明.md)。

普通应用窗口可以盖住面板。回到桌面时，程序会尝试在约一秒内恢复显示；不同 Windows 版本或第三方桌面软件可能影响这一行为。

## 数据

首次使用后，会在程序所在文件夹自动创建 `数据/待办.json`。每次写入前保留 `.bak` 备份；请将项目放在当前用户可写的文件夹中。

个人待办、设置、备份、错误日志和本地测试输出均已通过 `.gitignore` 排除。仓库截图使用演示事项。

移动或删除工具前，如已启用开机启动，请先在菜单中关闭；移动后可重新开启。

## 从源码编译

使用 Windows PowerShell：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\源码\build.ps1
```

脚本调用 Windows .NET Framework 自带的 C# 编译器，将 WPF 界面和图标嵌入 EXE。重新编译根目录 EXE 前，请先从托盘菜单退出正在运行的工具。

也可以构建到另一个文件以保留正在运行的版本：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\源码\build.ps1 -OutputPath .\桌面待办.next.exe
```

验证命令：

```powershell
.\桌面待办.exe --self-test
```

自检使用独立数据，覆盖保存与恢复、编辑删除、备份损坏保护、基本界面交互及折叠图标位置，并在 `测试结果/` 中输出报告与三种布局预览，不修改个人清单。

## 项目文件

- `源码/DesktopTodo.cs`：程序逻辑、持久化、系统托盘、Windows 窗口行为。
- `源码/MainWindow.xaml`：WPF 界面。
- `源码/build.ps1`：编译脚本。
- `源码/convert-icon.ps1`：由 AI 原图生成多尺寸 ICO。
- `素材/`：图标、生成提示词和演示截图。

此项目根据桌面小部件参考图独立实现，没有复制第三方项目代码。同类项目调研链接见 [使用说明](使用说明.md)。
